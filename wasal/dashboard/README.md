# Wasal Dashboard

لوحة تحكم منصة وصل - React/TypeScript

## التثبيت

```bash
npm install
```

## التشغيل

```bash
npm run dev
```

سيعمل على `http://localhost:3001`

## المميزات

- تسجيل دخول الأدمن
- نظرة عامة مع إحصائيات
- إدارة المندوبين
- إضافة رصيد للمندوبين
- اعتماد المندوبين
- إدارة الطلبات

## الاتصال بالـ API

يتم الاتصال بالخلفية على `http://localhost:5000/api`

## الصفحات

- `/login` - صفحة تسجيل الدخول
- `/dashboard` - لوحة التحكم الرئيسية
