# Wasal Front-end

تطبيق منصة وصل - React/TypeScript

## التثبيت

```bash
npm install
```

## التشغيل

```bash
npm run dev
```

سيعمل على `http://localhost:5173`

## المميزات

- الصفحة الرئيسية (Landing Page)
- تطبيق العميل (تسجيل، دخول، إنشاء طلبات)
- تطبيق المندوب (قبول طلبات، تحديث الموقع)
- نظام OTP للتسجيل واسترجاع كلمة المرور

## الاتصال بالـ API

يتم الاتصال بالخلفية على `http://localhost:5000/api`

## الخدمات

- `authAPI` - المصادقة
- `orderAPI` - إدارة الطلبات
- `driverAPI` - وظائف المندوب
- `userAPI` - إدارة المستخدم
